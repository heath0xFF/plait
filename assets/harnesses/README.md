# Harness logos

These marks identify which agent harness runs a thread. They are the harness
makers' trademarks, shown unmodified only to name the harness; they are not
Plait branding and imply no endorsement. Plait's own artwork is in
[branding](../branding/README.md).

| File | Shown for | Mark of |
|---|---|---|
| `openai.svg` | Codex threads | OpenAI |
| `pi.svg` | Pi threads | Pi |

Source: [Lobe Icons](https://github.com/lobehub/lobe-icons), npm package
`@lobehub/icons-static-svg` 1.103.0, MIT licensed (see `LICENSE-lobe-icons`).
The drawings are unchanged; only the web-only `width`, `height`, and `style`
attributes were removed so the app can size and tint them.
