PLAIT — EDITABLE VECTOR KIT
Reconstructed 15 November 2026

ABOUT THIS KIT
These are clean, manually redrawn SVG approximations of the Plait artwork
in the supplied raster image. A raster image contains pixels, not original
vector paths. It cannot yield the exact source geometry, original gradients,
font identity, or authoring layers. Curves, colors, proportions, folds and
lettering in this kit are reconstructed, and are not pixel-perfect originals.

EDITING
Open the SVG files in a vector editor such as Figma, Illustrator or Inkscape.
The primary P has four named pieces: stem, bowl, crown and ribbon. Gradient
stops and paths are directly editable. Thin highlight paths are separate.
Transparent space around the mark and inside the P is real transparency.
There are no bitmap images, external assets, scripts, filters or masks in
the logo files. App icon backgrounds are editable gradient rectangles.

The path wordmarks are custom letter shapes, not an identified source font.
They render without font installation. The live-text alternative requests
Avenir Next Bold, falling back to Arial; its appearance can vary by system.
The tagline is live Arial/Helvetica text and may also vary slightly by system.
For exact delivery of a tagline, convert its text to outlines in your editor.

USE
The filenames “light” and “dark” describe the LETTERING color: use light on
dark backgrounds and dark on light backgrounds. Color logos have transparent
backgrounds; the app icon includes a dark rounded tile with transparent margins.
Porcelain and graphite preserve the folded appearance; the solid marks are
single-color silhouettes. Outline marks use editable rounded strokes.
For very small display sizes, prefer the simpler solid mark.
UI icons use currentColor, initialized via the named group's color attribute.
Change that attribute to recolor them, or remove it to inherit a parent color
when inlining in HTML. External image tags do not inherit page color.

The app icon SVG is an editable master, not a compiled macOS .icns file.
No claim is made that these files have been tested in Plait's GPUI renderer.
